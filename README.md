# 핸즈온 머신러닝 2판 학습 노트

이 저장소는 『핸즈온 머신러닝 2판』(Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow) 책을 학습하며 실습한 내용을 정리한 곳입니다.

## 📚 프로젝트 구조

```
handson_ml/
├── practice_01+02.ipynb/py - 머신러닝의 개념과 첫 번째 머신러닝 프로젝트
├── practice_03.ipynb/py - 분류
├── practice_04.ipynb/py - 모델 훈련
├── practice_10.ipynb/py - 케라스를 사용한 인공 신경망 소개
├── practice_11.ipynb/py - 심층 신경망 훈련
├── practice_12.ipynb/py - 텐서플로를 사용한 사용자 정의 모델과 훈련
├── practice_13.ipynb/py - 텐서플로에서 데이터 로드와 전처리하기
├── practice_14.ipynb/py - 합성곱 신경망을 사용한 컴퓨터 비전
├── practice_15.ipynb/py - RNN과 CNN을 사용한 시퀀스 처리
└── practice_16.ipynb/py - RNN과 어텐션을 사용한 자연어 처리
```

## 📖 학습 내용

### Part 1. 머신러닝의 기초

- **1-2장**: 머신러닝의 기본 개념과 전체 프로젝트 실습
  - 지도 학습, 비지도 학습, 강화 학습의 개념
  - 캘리포니아 주택 가격 예측 프로젝트 실습
- **3장**: 분류
  - MNIST 데이터셋을 사용한 숫자 분류
  - 이진 분류기, 다중 분류기 구현
- **4장**: 모델 훈련
  - 선형 회귀, 로지스틱 회귀
  - 경사 하강법의 이해와 구현

### Part 2. 신경망과 딥러닝

- **10장**: 케라스 신경망 소개

  - 인공 신경망의 기초
  - 케라스를 사용한 모델 구현

- **11장**: 심층 신경망 훈련

  - 가중치 초기화와 활성화 함수
  - 배치 정규화, 드롭아웃 등 심층 신경망 학습 기법

- **12장**: 텐서플로 커스텀 모델

  - 텐서플로 2.0의 특징
  - 사용자 정의 모델과 훈련 루프 구현

- **13장**: 데이터 처리

  - 데이터 API 활용
  - 효율적인 입력 파이프라인 구축

- **14장**: 컴퓨터 비전

  - CNN의 구조와 원리
  - 이미지 분류, 객체 탐지 실습

- **15장**: 시퀀스 처리

  - RNN과 CNN을 활용한 시계열 데이터 처리
  - 시퀀스-투-시퀀스 학습

- **16장**: 자연어 처리
  - RNN과 어텐션 메커니즘
  - 텍스트 처리와 감성 분석

## 🛠 개발 환경

- Python 3.x
- 주요 라이브러리:
  - scikit-learn
  - TensorFlow 2.x
  - Keras
  - NumPy
  - Pandas
  - Matplotlib
